# Operator

Placeholder knowledge base for the public visitor chatbot. Replace this file with facts you are willing to tell strangers.

## About

This repo is the open-source personal-agent framework. The signed-in operator uses the Cursor Personal Agent. Visitors, if you enable the public chatbot, talk to a local gpt-oss model grounded in this file.

## Setup

Set `OWNER_EMAIL` in `server/.env`. Rename `education/you@example.com` to match. Do not put private mail, GPS, Health, or other people's data here.
