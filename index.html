A personal agent that lives on your Mac.

Open-source framework for a single-operator life OS: Cursor agent, file-tree brain, school dashboard, fitness, nightly jobs, optional Apple Mail / Messages / Health / location. The live reference is yanylevin.com.

What this is

A Mac-hosted personal agent. Express on localhost, Cursor SDK for the signed-in operator, optional local gpt-oss for visitors. Education, fitness, and dashboard UIs read a per-email folder tree. Apple integrations talk to the OS over a local Unix socket, not the public internet.

Yan Levin in this repo is a placeholder for the person who built the reference implementation. Fork it, set OWNER_EMAIL, rename the iOS target before you sign it.

Run it

Mac Express API

port 3004

Copy server/.env.example, set OWNER_EMAIL and CURSOR_API_KEY, then npm run server. Optional: LM Studio on :1234 for the public chatbot.

Dashboards

/education /fitness /dashboard

Static UI on Vercel or python3 -m http.server. Google OAuth is optional on localhost.
